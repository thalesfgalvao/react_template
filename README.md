## 🇧🇷 Português

Template base para projetos React desenvolvido para acelerar a criação de novas aplicações.

### ✨ Recursos

- ✅ TypeScript
- ✅ Styled Components
- ✅ Theme Provider
- ✅ Global Style
- ✅ React Router
- ✅ Estrutura organizada
- ✅ Pronto para expansão

---

### 📂 Estrutura

```text
src/
│
├── pages/
├── routes/
│   ├── Home
│   │   ├── index.tsx
│   │   ├── style.ts
│   ├── About
│   │   ├── index.tsx
│   │   ├── style.ts
│   ├── NotFound
│   │   ├── index.tsx
│   │   ├── style.ts
├── styles/
│   ├── GlobalStyle.ts
│   ├── theme.ts
│   └── styled.d.ts
│
├── App.tsx
└── index.tsx
```

---

### 🚀 Instalação

#### npm

```bash
npm install
npm run dev
```

#### yarn

```bash
yarn
yarn run dev
```
